WORKFLOW & ARCHITECTURE

Adding Courses & Interactive Visualizations

Everything runs as plain static HTML, CSS, and JavaScript. No bundler, no package install, and full support for opening index.html directly from disk.

Step 1 — Add a New Course Page

Takes two edits: create the HTML page and register it in the course list.

2 Steps
  1. Duplicate courses/_template.html as e.g. courses/cryptography.html and update data-page="cryptography" on <body>.
  2. Add a matching entry to js/courses-data.js. The Home Hub and sidebar update automatically on every page: 
{
  id: "cryptography",
  code: "CS-560",
  title: "Applied Cryptography",
  category: "Theory",
  color: "#e11d48",
  page: "courses/cryptography.html",
  description: "Modular arithmetic, Diffie-Hellman key exchange, and elliptic curve groups.",
  topics: ["Modular Inverse", "RSA", "Diffie-Hellman"],
  vizCount: 1
}

Step 2 — Drop In a Small Interactive Visualization

Each visualization is just a .viz-card block plus a short script using VizKit (or SVG / plain DOM).

Copy & Paste

Inside any course page's <div class="viz-stack">, paste a .viz-card skeleton: 

<section class="viz-card" id="viz-my-topic">
  <div class="viz-header">
    <div>
      <h2 class="viz-title">Modular Exponentiation (a^b mod p)</h2>
      <p class="viz-subtitle">Step through square-and-multiply in binary.</p>
    </div>
    <span class="badge">Number Theory</span>
  </div>

  <div class="viz-controls">
    <button id="my-step-btn" class="btn btn-sm btn-primary">Step</button>
  </div>

  <div class="viz-body">
    <div class="viz-stage"><canvas id="my-canvas"></canvas></div>
    <div class="viz-readout" id="my-readout">...</div>
  </div>
</section>

Then use VizKit in your script so your canvas stays sharp on Retina/4K screens and matches light/dark mode:

const canvas = document.getElementById("my-canvas");
function draw() {
  const { ctx, width, height } = VizKit.setupCanvas(canvas, 800, 260);
  const c = VizKit.getThemeColors();
  ctx.fillStyle = c.bg;
  ctx.fillRect(0, 0, width, height);
  // Draw nodes, lines, plots, etc. using c.accent, c.text, c.success...
}
canvas.addEventListener("pointerdown", (e) => {
  const pt = VizKit.getCanvasPoint(canvas, e, 800, 260);
  // pt.x, pt.y are in logical [0..800] x [0..260] coordinates
});
VizKit.onThemeChange(draw);
draw();

VizKit Reference

Available globally on every course page via ../js/viz-kit.js.

API Purpose
VizKit.setupCanvas(el, w, h) Sets responsive aspect ratio & HiDPI devicePixelRatio transform; returns { ctx, width, height }.
VizKit.getCanvasPoint(el, evt, w, h) Maps mouse/touch pointer coordinates accurately to logical (w, h) space.
VizKit.getThemeColors() Returns active CSS theme tokens (bg, grid, text, accent, success, warning, danger, purple).
VizKit.onThemeChange(fn) Calls fn whenever the user toggles Light/Dark mode so canvases redraw immediately.
