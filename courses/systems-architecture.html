Key Takeaway: Compulsory vs. Conflict Misses

On the default Conflict Thrashing trace (0x00, 0x20, ...) with 8 lines × 4B = 32B total capacity, both 0x00 and 0x20 map to Set 0 in a Direct-Mapped cache, causing repeated evictions (0% hit rate after initial loads). Switch Associativity to 2-Way Set Assoc and re-run: both tags coexist in Set 0, turning repeats into hits!

Key Takeaway: Why 0.1 cannot be represented exactly in binary

In base 2, 1/10 is a repeating fraction 0.0001100110011...₂. Rounding to 23 mantissa bits produces 0.10000000149011612 in float32. When all 8 exponent bits are 0 (E = 0) and mantissa is non-zero, IEEE 754 switches to Subnormal mode (no implicit leading 1, fixed exponent 2⁻¹²⁶) for gradual underflow toward zero.
