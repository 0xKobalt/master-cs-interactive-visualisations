Key Takeaway: Why Bayes' error ε* cannot be beaten by a better classifier

For any threshold t, total error is the yellow area where the chosen class has the smaller curve plus any extra tail you include by moving away from the intersection. Clicking Snap to Bayes Optimal places t right at p(x|y₁)p(y₁) = p(x|y₂)p(y₂), reaching ε*. Notice that moving t never reduces ε*—only changing the underlying distribution (like increasing class separation μ₂ − μ₁) lowers ε*.

Key Takeaway: Rescaling posteriors shifts the safe zone

When missing an illness (λ₂₁ = 100) is 10× costlier than a false alarm (λ₁₂ = 10), we only need p(ill|x) > 10/110 ≈ 9.1% before predicting Ill becomes the lower-risk decision! 4. Slide 53 Check: "Questions for you..."

Test your intuition on the reflection questions from the end of Lecture 1a before revealing each answer.

Slide 53
Q1: True or not — when you can estimate the posterior probabilities better, you can decrease the Bayes' error.

False. Bayes' error ε* is a property of the true underlying data distribution p(x, y) (class overlap), not of your estimator. Better posterior estimates move your classifier's error down toward ε*, never below it.

Q2: Will an empirical error estimate measured on the training set typically be larger, equal, or smaller than Bayes' error?

On the training set, an overfitted model can appear smaller than ε* (recall the darkened cat/green bean example on Slide 17!). On an independent test set (Slide 18), any real classifier's expected error is always ≥ ε* because ε* is the theoretical minimum over p(x, y).

Q3: What happens when p(y₁) = 2·p(y₂)?

Since p(y₁) + p(y₂) = 1, this means p(y₁) = 2/3 and p(y₂) = 1/3. The decision rule p(x|y₁)p(y₁) > p(x|y₂)p(y₂) becomes 2·p(x|y₁) > p(x|y₂), shifting the boundary toward class 2 and expanding region Ω₁. Try clicking Set p(y₁) = 2·p(y₂) in Visualization 1 above!
