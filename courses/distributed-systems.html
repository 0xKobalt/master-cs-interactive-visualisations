Key Takeaway: Lamport L(a) < L(b) does NOT imply a → b

Lamport clocks guarantee a → b ⇒ L(a) < L(b), but concurrent events a ∥ b can still have different scalar timestamps. Vector clocks close the gap in both directions: a → b ⇔ V(a) < V(b). In the default Sample Scenario, try clicking e2 on P2 and e5 on P3 to observe concurrency despite L(e2) < L(e5).

Key Takeaway: Why Dynamo / Cassandra use Virtual Nodes

With only 1 token per server, random hash placement produces uneven arc lengths (hotspots). Assigning V virtual nodes per physical server interleaves segments around the 32-bit hash ring, reducing key-count variance roughly by 1 / √V while keeping key churn minimal (O(K / N)) when a node joins or leaves.
