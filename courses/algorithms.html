Key Takeaway: Why A* explores fewer nodes than Dijkstra

BFS minimizes edge count (hops) and ignores terrain weights. DFS dives along one branch first and offers no shortest-path guarantee. Dijkstra expands in order of true cost from start g(n), guaranteeing optimal weighted paths. A* prioritizes f(n) = g(n) + h(n), where the admissible Manhattan heuristic h(n) pulls exploration toward T without ever overestimating remaining cost.

Key Takeaway: Inorder always yields sorted keys

Because every BST node satisfies left < node < right, an Inorder (L → N → R) traversal produces keys in strictly ascending sorted order. Preorder captures top-down structure (useful for serializing a tree), while Postorder processes children before parents (useful for deleting or evaluating expression trees).
